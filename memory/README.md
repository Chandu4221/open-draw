# Project Memory Bank

This directory contains persistent documentation and context for the `open-draw` project. It is maintained and updated periodically as the project evolves.

## Structure

- [`context.md`](./context.md): Current high-level state of the project, package layout, and active focus.
- [`architecture.md`](./architecture.md): Architectural decisions, component boundaries, and design principles.
- [`decisions.md`](./decisions.md): Architecture Decision Records (ADRs) and key technical choices.
- [`progress.md`](./progress.md): Implementation milestones, completed features, and upcoming roadmap items.

## Maintenance Guidelines
- Update this directory periodically when new components are introduced, major architecture decisions are made, or milestones are reached.
- Keep documentation concise, accurate, and actionable.
