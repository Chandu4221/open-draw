# Project Memory Bank

This directory contains persistent documentation and context for the `open-draw` project. It is maintained and updated periodically as the project evolves.

## Structure

- [`context.md`](file:///home/chandra/myfiles/open-draw/memory/context.md): Current high-level state of the project, package layout, and active focus.
- [`architecture.md`](file:///home/chandra/myfiles/open-draw/memory/architecture.md): Architectural decisions, component boundaries, and design principles.
- [`decisions.md`](file:///home/chandra/myfiles/open-draw/memory/decisions.md): Architecture Decision Records (ADRs) and key technical choices.
- [`progress.md`](file:///home/chandra/myfiles/open-draw/memory/progress.md): Implementation milestones, completed features, and upcoming roadmap items.

## Maintenance Guidelines
- Update this directory periodically when new components are introduced, major architecture decisions are made, or milestones are reached.
- Keep documentation concise, accurate, and actionable.
